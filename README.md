# Plant Reminder Assistant

> **Brought to you by GitLabsVPN**

### 🌱 App Overview

This is a simple iPhone app that lets you set customized plant care reminders based on:

- **Plant name**
- **Location** (user’s or manually entered)
- **Time zone awareness**
- **Photo-based identification (optional)**

### 🧰 Features

- Add reminders via photo or input
- Time zone awareness (based on user location)
- Calendar integration (Apple calendar)

### 📝 Requirements

- Xcode (preferably latest version)
- iOS 15 or higher
- Core Data (for offline persistence)
- EventKit (for calendar access)

### 🛠️ How to Run

1. Clone this repository
2. Open the project in Xcode
3. Run the app
